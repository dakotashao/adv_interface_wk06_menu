# adv_interface_wk06_menu

Advanced Interface, week 6: Menu.

| Set | Concept | Prototype |
|---|---|---|
| 1 | Liquid Dial: a smart-home menu as one liquid rotary dial over the room. Turn to choose a device, press to open its options; the open lobe is the device itself (tap to switch on/off or play/pause). Background switch: the original blurred colour field, or the live room photo; over a dark room the dial turns to frosted glass | [Open](https://dakotashao.github.io/adv_interface_wk06_menu/liquid-dial/) |
| 2 | Dominoes Jukebox: a music menu on a screen and one knob. Turn to move, press to go in, hold (or Back) to come back; albums tip back like dominoes, songs run on a ruler, then actions with an Add to playlist submenu | [Open](https://dakotashao.github.io/adv_interface_wk06_menu/dominoes-jukebox/) |

Each set lives in its own folder with a self-contained `index.html`. Spec is inside each prototype (Spec button).
